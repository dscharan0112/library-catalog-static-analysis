# Reflection on Static Code Analysis

## 1. What did I learn?
I learned how static code analysis tools identify code-quality problems, formatting issues, unsafe functions, and weaknesses in error handling.

## 2. Which tool was most useful?
Bandit was useful for identifying potential security concerns, while Flake8 helped identify unused imports, unused variables, and formatting issues. Pylint provided additional code-quality feedback.

## 3. What challenges did I face?
I had to understand the warnings and distinguish potential security risks from ordinary style issues. I also needed to ensure that code improvements did not change the expected functionality of the library catalog system.

## 4. What would I improve in the future?
I would add automated tests, improve exception handling, validate user input, avoid unsafe functions, and rerun static analysis after every significant code change.
